# Low-Level Programming in C

**Holberton School · Software Engineering Coursework**

Foundational C exercises focusing on algorithms, memory, pointers, data structures and low-level input/output.

## Technology and concepts

C, pointers, memory management, linked lists, file I/O, function pointers and hash tables.
